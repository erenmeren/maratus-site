# maratus

A small screen for the counter. The business decides what the customer gets on it: a digital
receipt, an offer, a loyalty card, a ticket, or anything else, and the customer opens it on their
own phone.

This branch is what GitHub Pages serves for https://maratus.co. Plain HTML, CSS and ES modules,
no build step. three.js is vendored under `vendor/three/` (MIT). The Gabarito font is under
`assets/fonts/` (SIL Open Font License, see `OFL.txt`).

| path | what it is |
|---|---|
| `index.html` | the home page |
| `technical/` | the technical page |
| `docs.html` | redirects to https://docs.maratus.co |

Source and design history: branch `design/v3`.
